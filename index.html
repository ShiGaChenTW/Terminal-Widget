▸ 開始安裝 看看功能

01核心功能

不是把命令輸出抓回來貼到畫面 — 是把整個 xterm.js 真實終端嵌進桌面。

02安裝

五分鐘從零到桌面有個 widget。

相依軟體

Übersicht
桌面 widget 框架
ttyd
終端機後端
Homebrew
套件安裝
Python 3
install.py 引擎
1

安裝相依工具

Übersicht 是顯示框架，ttyd 是真正跑終端的引擎。

brew install --cask ubersicht
brew install ttyd
2

把 widget 放進 Übersicht

整個資料夾複製過去：

cp -R terminal-widget.widget \
   "$HOME/Library/Application Support/Übersicht/widgets/"
3

跑互動安裝程式（推薦）

會自動分配 port、設定招呼語、AUTORUN 指令，並可一次建立多個獨立實例。

cd "$HOME/Library/Application Support/Übersicht/widgets/terminal-widget.widget"
python3 install.py

互動流程會問你：

    4

    啟動

    Übersicht 選單列 → Refresh All Widgets。約半秒後會看到桌面浮現一個終端機，就完成了。

    05調整 Widget 的 Skill

    隨 widget 一起出貨的 Claude Code skill 檔，把整套架構、常見除錯陷阱、標準骨架封裝成一份可被 AI 載入的方法論。

    ⚡
    uebersicht-interactive-widget
    建構 Übersicht 互動式桌面 widget 的方法論 Skill
    SKILL.md

    這份 skill 把今天從零打造這個 widget 的整段經驗濃縮成一份結構化的指南。在 Claude Code session 內呼叫它，AI 就會帶著正確的心智模型來幫你修改 widget — 不會走我們已經踩過的彎路。

    如何呼叫

    Skill("uebersicht-interactive-widget")
